## 📖 About

A static web page that explains the demonetisation of ₹500 and ₹1,000 banknotes, announced by the Government of India on **8 November 2016**. It covers:

- 🗓️ What was announced and when
- 🎯 The stated goals: curbing counterfeit currency, black money and corruption
- 🏧 The immediate impact: cash shortages, long queues and market reaction
- 💬 The support and criticism the move received

---

## 👀 View it

No build step and no dependencies.

1. Download or clone the repo
   ```bash
   git clone https://github.com/agnibeshduttaroy/Demonetisation.git
   ```
2. Open **`Demonetisation.htm`** in any browser
